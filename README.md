### 🚀 Featured Projects

#### 1. 💬 SecureChat — End-to-End Encrypted Messaging Platform
[![Live Demo](https://img.shields.io/badge/Live_Demo-Visit-success?style=flat-square&logo=vercel)](https://secure-chat-e2e.vercel.app/)



> **Tech Stack:** `Python` `Flask` `Socket.IO` `MongoDB` `WebCrypto API (RSA + AES-256-GCM)` `PBKDF2`
- **Zero-Knowledge Architecture:** End-to-end encrypted in the browser via WebCrypto API; server and database store strictly ciphertext. Client private keys are non-extractable and never transmitted. 
- **Real-Time Collaboration:** Powered by Flask-SocketIO for instant messaging, live typing indicators, presence tracking, and encrypted group chats (up to 60 members).
- **Authentication & Security:** Email OTP registration with automated token expiration and password hashing.

#### 2. 📄 AI-Based Resume Screening & Job Matching System
[![GitHub Repo](https://img.shields.io/badge/GitHub-Repository-181717?style=flat-square&logo=github)](https://github.com/shiva272153/AI-RSS)

> **Tech Stack:** `React.js` `Node.js` `Express.js` `Flask` `MongoDB` `scikit-learn` `NLTK` `Recharts`
- **Multi-Role Recruitment Platform:** Dual-role architecture (Candidate/Recruiter). Candidates upload PDF/DOCX resumes for automated match breakdown; recruiters can batch-screen applicants with 1-click.
- **Microservice NLP Pipeline:** Separate Python Flask microservice handles tokenization, NLTK preprocessing, and n-gram TF-IDF vectorization with cosine similarity scoring.
- **Hybrid Scoring Algorithm:** Combines 60% TF-IDF semantic relevance with 40% keyword match against a custom 250+ skill ontology, highlighting exact matching and missing skill sets.
- **Interactive Analytics:** Role-based JWT authentication with dynamic React dashboards rendered via Recharts.

#### 3. 🩺 MediPredict AI: Disease Prediction System
[![GitHub Repo](https://img.shields.io/badge/GitHub-Repository-181717?style=flat-square&logo=github)](https://github.com/shiva272153/MediPredict-AI/)

> **Tech Stack:** `Python` `Flask` `scikit-learn` `Pandas` `Chart.js` `Joblib`
